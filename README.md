# 📊 Vrinda Store Data Analysis using Advanced Excel

![Vrinda Store Dashboard](https://github.com/user-attachments/assets/433bcbd5-166f-460f-a14c-e67f7c727055)

This project showcases an **interactive sales analysis dashboard** created using **Advanced Microsoft Excel**. It focuses on analyzing key metrics of **Vrinda Store** such as sales trends, top-performing products, customer segments, and revenue patterns to aid in business decisions.

---

## 📌 Project Overview

The goal of this project is to provide actionable insights for Vrinda Store by analyzing historical sales data. Using Excel’s advanced features, a dashboard was created that highlights critical business metrics like product-wise sales, customer insights, and monthly performance trends.

---

## 🔍 Key Highlights

- 📅 **Monthly Sales Trends**: Identify peak and low-performing months
- 🛍️ **Top-Selling Products**: Highlight most profitable and in-demand items
- 👥 **Customer Insights**: Understand frequent buyers and behavior
- 📦 **Category Analysis**: Track performance across product categories
- 📍 **Region-wise Sales**: Compare regional contributions to total revenue

---

## ⚙️ Excel Features Used

- ✅ **Pivot Tables** for dynamic data summarization  
- ✅ **Pivot Charts** for visual insights  
- ✅ **Slicers** for easy data filtering  
- ✅ **Formulas**: `VLOOKUP`, `IF`, `SUMIFS`, `COUNTIFS`  
- ✅ **Conditional Formatting** to highlight KPIs  
- ✅ **Dashboard Design** using linked charts and tables
